# 📊 Projeto Big Data - DoeVida

## Descrição do Projeto
Este projeto tem como objetivo analisar dados relacionados ao sistema DoeVida, aplicando técnicas de tratamento, organização e estruturação de dados para gerar insights estratégicos.

## Objetivo
- Organizar dados brutos
- Padronizar categorias
- Analisar informações por bairro e sexo
- Gerar relatórios para apoio à decisão

## Estrutura do Projeto
- dado sem tratamento.txt → Dados brutos
- planilha tratada.xlsx → Dados organizados
- codigo 1 organizacao colunas.txt → Código de tratamento
- documentacao_projeto.pdf → Documentação completa

## Sobre o Projeto

O DoeVida é um Produto Mínimo Viável (MVP) desenvolvido na disciplina Projeto Profissional de Big Data do Curso Técnico em Ciência de Dados da Escola do Futuro José Luiz Bittencourt – Goiânia/GO.

## Problema Identificado

Foi identificado um baixo índice de doadores ativos nos hemocentros de Goiânia, gerando situações frequentes de estoque crítico de bolsas de sangue.

A ausência de comunicação personalizada e baseada em dados reduz a recorrência das doações e compromete a eficiência na distribuição dos suprimentos.

## Público-Alvo

Pessoas entre 18 e 50 anos, em boas condições de saúde e aptas à doação de sangue conforme critérios estabelecidos pelos órgãos de saúde.


## Proposta de Valor

O aplicativo DoeVida integra:

- Dados de estoque
- Geolocalização
- Grau de urgência por tipo sanguíneo

O sistema envia notificações inteligentes aos doadores quando há necessidade urgente do seu tipo sanguíneo em determinada região, além de alertas quando estiverem próximos a pontos de coleta.


## Base de Dados

Dados provenientes do Banco de Dados do Hemocentro Goiás, contendo informações sobre:

- Tipos sanguíneos
- ⁠Doadores por setores de Goiânia 

Os dados foram organizados, tratados e padronizados para viabilizar análises e modelagem.
